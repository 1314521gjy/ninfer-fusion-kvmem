# docs 目录说明（**口径分层**）

本目录混着两批文档，读之前先分清：

| 批次 | 文件 | 口径 |
|---|---|---|
| **当前口径** | `编译指南-怎么编.md`（仓根）· `README.md`（仓根）· `NOTICE.md`（仓根）· `已知问题-初期版本.md`（仓根）· `实测回执与反馈.md`（仓根） | 与当前源码树、当前发布件一致；**冲突时以仓根这几份为准** |
| **历史口径** | `00`–`06`、`08`、`09`、`11`、`12`（**没有 07 / 10**）、`判据.txt`、`方案/` | 写于早期分发包阶段：里面的**数字、文件名、路径、批次结论**都是**当时那批包**的读数，机换了/包换了就不适用；机制与排查思路仍然有效 |

引用纪律：历史口径里的读数**照用前先复核**；涉及许可/署名的内容一律以仓根 `NOTICE.md` 为准。
